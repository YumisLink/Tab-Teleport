# TTP（Tab Teleport）

Forge 客户端模组：用 Tab 打开面板，快速传送与坐标标记。

## 功能

- **玩家传送**：按 Tab（玩家列表键）打开在线玩家列表，点「传送」传送到该玩家身边（旁观或已死亡的目标不可传）。
- **临时标记**：绑定「放置标记」键，对准方块放置；他人列表里你的「标记点」可用时，可传到你标记的位置。
- **标记队列**：按住 Ctrl 再放置标记，写入 3 个持久槽位；槽位满时选择替换；在面板顶部点「传送」传送到对应槽位；点击槽位名称可重命名。
- **跨维度**：标记与传送支持不同维度（按服务端存储的维度与坐标执行）。

## 环境

- Minecraft **1.20.1**，Forge 47+
- 服务端与客户端均需安装本模组

## 构建

```powershell
.\gradlew.bat build --no-daemon
```

产物：`build/libs/ttp-1.0.0.jar`
